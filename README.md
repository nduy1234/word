# Word: Wake Your Room

Hands-only mixed-reality English-vocabulary game for Meta Quest 3/3S (English learners, CEFR A1–A2, ages 10+). The Hush fog stole the names of everything in your real room. Poke, pinch, flick, speak, or gaze-pinch to name real and table-diorama objects in English and wake them with color and sound. Built with IWSDK/TypeScript for the Meta VR Start Developer Competition 2026 (Gaming, New Experience).

- Hands-only end to end; no controller ever required. Seated, within two-foot reach.
- Head gaze = head-gaze reticle + pinch (Quest 3/3S has no eye tracking).
- Complete and fully playable with AI and network off: every AI feature has a local fallback.

## Setup

```bash
npm install
cp .env.example .env.local   # fill META_API_KEY if testing AI routes (optional)
npm run dev                  # IWSDK CLI-managed dev server + Immersive Web Emulator
```

Commands: `npm run typecheck` (tsc --noEmit), `npm test` (vitest), `npm run build` (vite), `npm run dev:status`.

## Environment variables

| Var | Where | Purpose |
|---|---|---|
| `META_API_KEY` | `.env.local` (local) / Vercel env vars (production) | Server-only key for Meta Model API. Read only by `api/_shared.ts` and `api/transcribe.ts`. Never in client code, never committed. |

Without the key the game runs fully offline: scripted Echo lines, seed packs, `speechSynthesis` → caption audio chain.

## Content packs

Seed content lives in `src/word/pack.ts` and as JSON in `packs/en/{room}.json` (generated by `pipeline/generate_packs.py`). Each word entry:

```json
{ "id": "cup", "word": "cup", "ipa": "/kʌp/", "partOfSpeech": "noun",
  "plural": "cups", "article": "a", "cefr": "A1", "example": "The cup is hot.",
  "helper": { "es": "la taza", "vi": "cái cốc" }, "propId": "cup",
  "wakeFx": "bloom", "rarity": "common", "audio": "audio/en-US/cup.mp3" }
```

`article` is stored in data ("a" | "an"), never computed at runtime. Districts unlock in order Home → Kitchen → Café → Market at 80% of the previous district awake.

### Add a word / room / spell

- **Word:** add a `WordEntry` to the right list in `src/word/pack.ts` (`ROOM_WORDS`, `KITCHEN_PROPS`, `CAFE_PROPS`, `VERBS`, `PHRASAL_VERBS`, `PREPOSITIONS`, `ADJECTIVES`), add its id to the district in `src/word/progression.ts` if it is a district word, then run `python pipeline/generate_packs.py` to refresh JSON packs. Audio clip (optional) goes to `public/audio/en-US/<id>.mp3` and gets an `ASSETS.md` row.
- **Room:** add a pack file `packs/en/{room}.json` with the same entry schema; scene-label words need `sceneLabel` matching a Quest semantic label (`table`, `wall`, `door`, ...). Unknown labels are skipped safely at runtime.
- **Spell:** spells are built from tiles (`src/word/spell-tiles.ts` `TILE_IDS`) and grammar rules in `src/word/spell.ts`. Add the word entry first, then the tile id; grammar (article agreement, adjective order, plurals) is unit-tested — run `npm test`.

### Add a helper language

Helpers live on each entry (`helper: { es, vi }`). To add one: extend `HelperLang` in `src/word/helper.ts`, add the field to every entry, add it to the palm-menu cycle. UI stays English; helpers are hints only and hide in Immersion mode.

## Testing on Quest

1. `npm run dev` (or open the deployed URL) on the same network as the Quest.
2. Quest Browser → dev-server URL (or production URL) → **Enter your room** (MR) or **Play in VR instead**.
3. Run the checklists in `docs/QA.md` (P0/P1/P2 tables, performance budget: ≥60 fps, <100 draw calls, ~150k triangles).
4. Test at least every other day on a real Quest 3; also test Quest 3S for FoV/text size. Desktop fallback: Immersive Web Emulator (metaQuest3 + sunlit_living_room).

## API usage estimate (through Dec 11)

Server routes rate-limit per IP (`api/_shared.ts`, `api/transcribe.ts`) and cache responses, so judge traffic stays small:

- Echo (`muse-spark-1.3`, docs-verified $1.25/$4.25 per Mtok): ≈300 input + 80 output tokens per call, ≤3 AI Echo calls/session + room-pack call per label-set (cached 1h server-side). 500 judge sessions ≈ 0.2M tokens ≈ **under $1**.
- Transcribe (docs-verified $3.00/1000 min): 3s clips; 500 sessions × 10 clips ≈ 250 min ≈ **$0.75**.
- Total expected spend through Dec 11: **< $5**, far inside the docs-verified rate limits (1.1 tier: 3000 RPM / 4M TPM; ASR 256 concurrent streams). Model availability/pricing is docs-verified only — see `docs/tooling.md`; if a keyed call fails, routes fall back silently and nothing is claimed.

## Privacy

Room geometry, scene data, and voice never leave the device — except: semantic label names only for the room-aware curriculum; voice clips only after opt-in consent at first mic use, transcribed server-side, never stored or logged. No analytics capturing room data.
